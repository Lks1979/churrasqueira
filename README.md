# Controle da Churrasqueira

Aplicação Angular para organizar as reservas da churrasqueira e acompanhar os pagamentos.

## Requisitos

- Node.js
- npm

## Executar localmente

```bash
npm install
npm start
```

Abra `http://localhost:4200/` no navegador. A aplicação recarrega automaticamente quando os arquivos são alterados.

## Compilar

```bash
npm run build
```

Os arquivos de produção são gerados em `dist/churrasqueira/`.

## Dados

As reservas são armazenadas no `localStorage` do navegador. Elas não são compartilhadas entre dispositivos ou navegadores.
